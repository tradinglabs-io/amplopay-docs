---
title: "API blocked"
description: "What to do when the API is blocked"
---

If the API is blocked, check the following:

- Whether your credentials are correct.
- Whether your account has permission to use the API.
- Whether your application IP must be authorized in the API settings.
- Whether there is a block due to location, plan, or security rules.

If you have questions, contact `{settings.supportEmail}`.
