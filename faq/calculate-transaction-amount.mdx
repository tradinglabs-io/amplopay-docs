---
title: "Calculate transaction amount"
description: "How to calculate the amount sent to the API"
---

The transaction amount must represent the total charged to the customer.

```text
amount = sum of products + shippingFee + extraFee - discount
```

Example:

```json
{
  "products": [
    { "name": "Produto 1", "quantity": 1, "price": 80 },
    { "name": "Produto 2", "quantity": 2, "price": 10 }
  ],
  "shippingFee": 15,
  "extraFee": 5,
  "discount": 10,
  "amount": 110
}
```
