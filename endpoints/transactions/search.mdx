---
title: "Search transactions"
description: "Query transactions created through the API"
---

```http
GET /gateway/transactions
```

Queries created transactions.

<Warning>
  Do not use this endpoint for frequent polling. Configure webhooks to receive real-time status updates.
</Warning>

## Query params

| Field | Type | Required | Description |
| --- | --- | --- | --- |
| `id` | string | no | Transaction ID returned by the API |
| `clientIdentifier` | string | no | Identifier you sent when creating the transaction |
