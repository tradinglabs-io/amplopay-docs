---
title: "Request refund"
description: "Request a refund for a producer transaction"
api: "POST /gateway/producer/refunds"
---

Requests a refund for a transaction owned by the authenticated producer.

## Body parameters

<ParamField body="transactionId" type="string" required>
  ID of the transaction to refund.
</ParamField>

<ParamField body="reason" type="string">
  Reason for the refund request.
</ParamField>

## Request example

<RequestExample>

```bash
curl --request POST \
  --url {API_BASE_URL}/gateway/producer/refunds \
  --header 'Content-Type: application/json' \
  --header 'x-public-key: SUA_CHAVE_PUBLICA_AQUI' \
  --header 'x-secret-key: SUA_CHAVE_PRIVADA_AQUI' \
  --data '{
    "transactionId": "transaction_id",
    "reason": "Requested by the customer"
  }'
```

</RequestExample>
