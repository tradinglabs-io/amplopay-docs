---
title: "Create crypto charge"
description: "Create a cryptocurrency charge"
api: "POST /gateway/crypto/receive"
---

Creates a cryptocurrency charge.

## Body parameters

<ParamField body="identifier" type="string" required>
  Unique identifier for this transaction in your application.
</ParamField>

<ParamField body="amount" type="number" required>
  Transaction amount.
</ParamField>

<ParamField body="currency" type="string" required>
  Fiat currency used as the transaction reference amount.
</ParamField>

<ParamField body="cryptoCurrency" type="string" required>
  Cryptocurrency used for the payment.
</ParamField>

<ParamField body="network" type="string" required>
  Blockchain network used for the payment.
</ParamField>

<ParamField body="client" type="object" required>
  Customer information.
</ParamField>

<ParamField body="callbackUrl" type="string">
  URL that will receive payment status webhook notifications.
</ParamField>

## Request example

<RequestExample>

```bash
curl --request POST \
  --url {API_BASE_URL}/gateway/crypto/receive \
  --header 'Content-Type: application/json' \
  --header 'x-public-key: SUA_CHAVE_PUBLICA_AQUI' \
  --header 'x-secret-key: SUA_CHAVE_PRIVADA_AQUI' \
  --data '{
    "identifier": "crypto-123",
    "amount": 100,
    "currency": "BRL",
    "cryptoCurrency": "USDT",
    "network": "TRON",
    "client": {
      "name": "João da Silva",
      "email": "joao@email.com",
      "phone": "(11) 99999-9999",
      "document": "123.456.789-00"
    },
    "callbackUrl": "https://minha-api.com/webhooks/payment"
  }'
```

</RequestExample>
